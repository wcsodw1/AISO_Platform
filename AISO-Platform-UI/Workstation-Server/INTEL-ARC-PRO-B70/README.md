# Intel Arc Pro B70

Intel Arc Pro B70 為工作站級獨立 GPU。本目錄暫歸 Workstation-Server；整機型號、機箱形式、GPU 數量及作業系統待確認。

- `Scripts/`：此機器的執行腳本。
- `Documents/`：設備文件與操作說明。
- `Benchmark/`：整理後的測試結果。
- 各項 `Public/`：經審核可公開的內容。

分類依據：https://www.intel.com/content/www/us/en/products/details/discrete-gpus/arc/workstations/b-series.html
