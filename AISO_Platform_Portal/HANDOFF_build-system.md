## Calculation (one model)
requests at once = ceil(people x 30%); NP = highest tested NP with per-request tok/s >= 15 x 1.07 at the chosen length (`okAt`); machines = ceil(need / NP). A model with no NP passing is still counted with NP1 and flagged (never 0 / cross). Memory pre-check = weights (GGUF bytes from the AISO1 dataset) vs 90% of VRAM. Spare machine: hidden, always off (David: too expensive).
Capacity labels: B70 GPU 32 x 2 = 64 GB; B60 GPU 48 x 2 = 96 GB (dataset says "48 GB x 2"); AISO1 GPU share 64 GB (128 GB unified) - David wrote 32x2 for AISO1 too, unconfirmed.

## Assumptions to keep labelled "not measured"
30% of people ask at the same moment (NVIDIA RAG example uses 10% for 1,000 people); input ranges above; B60 llama.cpp ran at batch 4096 vs 1024 on B70/AISO1 (not exact match).
